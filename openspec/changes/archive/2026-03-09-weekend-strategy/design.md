## Context

加密貨幣市場 24/7 運作，但週末交易量和借款需求明顯降低。放貸方如果不調整利率，容易在週末低利率環境下成交。Weekend Premium 在週末時段加入溢價以補償。

## Goals / Non-Goals

**Goals:**
- 根據星期幾決定溢價倍率
- 週六溢價最高，週日遞減，週五晚間小幅溢價
- 純計算，滿足 Apply 介面

**Non-Goals:**
- 不做時區轉換（使用 UTC）
- 不考慮假日（假日由 D12 Calendar 負責）

## Decisions

### 1. 溢價時間表

| 時段 | 溢價倍率 |
|---|---|
| 週一至週四 | ×1.00（不調整） |
| 週五 18:00+ UTC | ×1.02（+2%） |
| 週六 | ×1.05（+5%） |
| 週日 | ×1.03（+3%，遞減） |

### 2. 時間來源

使用 MarketSnapshot.Timestamp 作為時間基準，若為零值則使用 time.Now()。支援注入 `now` 函數以便測試。

## Risks / Trade-offs

- **[溢價倍率硬編碼]** → 後續可參數化
- **[不考慮實際流動性]** → 純時間驅動，簡單但可能與實際情況偏差
