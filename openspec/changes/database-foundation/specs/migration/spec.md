## ADDED Requirements

### Requirement: Atlas declarative schema
The database schema SHALL be defined declaratively in `schema/schema.hcl` as the single source of truth.

#### Scenario: Schema definition
- **WHEN** a developer reads `schema/schema.hcl`
- **THEN** it SHALL contain the complete desired state of all database tables

### Requirement: Atlas project configuration
The `schema/atlas.hcl` SHALL configure Atlas with the database connection and migration directory.

#### Scenario: Atlas configuration
- **WHEN** running `atlas migrate diff`
- **THEN** Atlas SHALL read `schema/atlas.hcl` to determine the database source and migration output directory

### Requirement: Versioned migrations
Migration files SHALL be stored in `migrations/` and auto-generated by Atlas from schema changes.

#### Scenario: Generate migration from schema change
- **WHEN** a developer modifies `schema/schema.hcl` and runs `make migrate-diff`
- **THEN** Atlas SHALL generate a new timestamped SQL migration file in `migrations/`

#### Scenario: Apply migrations
- **WHEN** a developer runs `make migrate-apply`
- **THEN** Atlas SHALL apply all pending migrations to the target database

### Requirement: Initial users table
The initial schema SHALL include a `users` table with: `id` (UUID, PK), `email` (unique), `password_hash`, `status` (default 'active'), `created_at`, `updated_at`.

#### Scenario: Users table exists after migration
- **WHEN** all migrations are applied
- **THEN** the `users` table SHALL exist with the specified columns and constraints

### Requirement: Makefile commands for migration workflow
The Makefile SHALL provide commands for common migration operations.

#### Scenario: Available migration commands
- **WHEN** a developer runs `make help` or reads the Makefile
- **THEN** the following commands SHALL be available: `make migrate-diff`, `make migrate-apply`, `make sqlc`
