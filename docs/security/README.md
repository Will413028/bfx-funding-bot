# Security documents

- Reporting a vulnerability: [`SECURITY.md`](../../SECURITY.md).
- The threat model (Shostack four questions, STRIDE) is held by the maintainer and is not
  published: it lists weaknesses that are not yet fixed. Fixes land as ordinary PRs that
  describe the control they add, not how the weakness could be used.
- The OWASP ASVS 5.0 Level 2 verification is published here once every requirement it
  judges as not met is either fixed or accepted with a reason.
