# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: **Security → Report a vulnerability**
on this repository. Please do not open a public issue for a security problem.

Include the affected component (backend, frontend, deployment), steps to reproduce,
and the impact you expect. You should receive an acknowledgement within 7 days.

## Supported versions

Only the current `main` branch, which is what production runs, receives fixes.
