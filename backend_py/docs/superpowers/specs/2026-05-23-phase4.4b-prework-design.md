## Design

### Deliverable 1 — `AxiomReplayQueryAdapter`

**Path**: `backend_py/src/bfx_funding_bot/modules/execution/axiom_event_query.py` (新)

**Pattern**: Hexagonal port-per-consumer + 1 shared adapter (Cockburn 2005 / Stripe-style domain-typed methods on shared EventStore)

```python
class AxiomReplayQueryAdapter:
    """Real Axiom APL adapter satisfying ledger + registry replay protocols.

    Conforms to:
      - modules/execution/ledger.py:_AxiomQueryProtocol — query_order_events(account_id, since)
      - modules/execution/registry_offers.py:_AxiomQueryProtocol — fetch_events(**kwargs)
    """

    def __init__(self, *, api_key: str, dataset: str,
                 base_url: str = "https://api.axiom.co", timeout: float = 30.0) -> None: ...

    async def query_order_events(
        self, account_id: str, since: datetime,
    ) -> list[dict[str, Any]]:
        """Ledger replay protocol — events for one account from a time anchor."""
        apl = self._build_ledger_apl(account_id, since)
        return await self._query_apl(apl)

    async def fetch_events(
        self, *, event_types: list[str], up_to_ms: int | None = None,
        account_id: str | None = None,
    ) -> list[dict[str, Any]]:
        """Registry replay protocol — events filtered by type and upper bound."""
        apl = self._build_registry_apl(event_types, up_to_ms, account_id)
        return await self._query_apl(apl)

    async def _query_apl(self, apl: str) -> list[dict[str, Any]]: ...
    def _build_ledger_apl(self, account_id: str, since: datetime) -> str: ...
    def _build_registry_apl(
        self, event_types: list[str], up_to_ms: int | None, account_id: str | None,
    ) -> str: ...
    async def aclose(self) -> None: ...
```

**APL projection** (full payload, unlike SmokeQueryAdapter 只取 3 欄):
```apl
['<dataset>']
| where ['event_type'] in (<types>)
  [and ['account_id'] == '<account_id>']      # optional filter
  [and _time > datetime(<since>)]              # ledger path
  [and _time <= datetime(<up_to_ms iso>)]      # registry path
| project _time, ['event_type'], ['account_id'], ['correlation_id'], ['payload']
| order by _time asc
```

**Row shape contract** (consumers expect):
```python
{
    "_time": "2026-05-23T14:00:00Z",    # ISO datetime str
    "event_type": "reservation_claimed",  # str enum
    "account_id": "default",
    "correlation_id": "<uuid str>",
    "payload": { ... }                    # event payload dict (Axiom flattens nested objects; need to verify)
}
```

**Axiom payload flattening risk** (4.4 prework lesson `9261f3f`): Axiom 把 nested object 展成 dot-notation column。即 `payload.cid` 是 column 不是 nested dict。`_query_apl` 必須測 raw response → 看 tabular field 是否 `payload` 或 `payload.cid` 等 dot-notation，必要時 re-nest 成 dict 給 consumer。

**Wire in `daemon.build_daemon`**:
- 刪 `_AxiomQueryAdapter` (line 548) + `_OfferRegistryQueryStub` (line 571)
- `axiom_query = AxiomReplayQueryAdapter(api_key=config.axiom_api_key, dataset=config.axiom_dataset)`
- Ledger uses `axiom_query`（同個 instance）
- Registry uses `axiom_query`（同個 instance）
- Daemon shutdown 加 `await axiom_query.aclose()`

**Rename existing**:
- `modules/admin/axiom_query.py:AxiomEventQueryAdapter` → `AxiomSmokeQueryAdapter`
- 更新 import: `modules/admin/smoke_runner.py`
- 更新 tests: `tests/modules/admin/test_axiom_query.py`

### Deliverable 2 — `BitfinexLiveExecutor.cancel` REST + `CancelAcknowledged` event

**Path**: `backend_py/src/bfx_funding_bot/external/bitfinex/live_executor.py` (改)

**New event** in `modules/execution/events.py`:
```python
@dataclass(frozen=True, slots=True)
class CancelAcknowledged:
    """Bitfinex REST cancel API returned (success OR already-terminal).

    Audit-only event — ledger/registry NOT subscribers. ws_dispatcher will
    later publish ReservationReleased when WS foc arrives.
    """
    venue_offer_id: str
    acknowledged_at_ms: int
    signal_correlation_id: UUID
    account_id: str
    rest_status: str  # "success" | "already_terminal"
    venue_response_text: str | None = None  # Bitfinex 9th element TEXT
    venue_seq: int | None = None  # always None — not WS-sourced
    event_seq: int | None = None
    occurred_at_ms: int | None = None
    recorded_at_ms: int | None = None
```

**Cancel REST endpoint** per https://docs.bitfinex.com/reference/rest-auth-cancel-funding-offer

```python
_OFFER_CANCEL_PATH = "v2/auth/w/funding/offer/cancel"

async def cancel(
    self, *, venue_offer_id: str,
    signal_correlation_id: UUID, account_id: str,
    ctx: AccountContext,
) -> None:
    """1. Publish CancelRequested (intent audit)
       2. POST cancel to Bitfinex with sign_request
       3. Publish CancelAcknowledged (REST ack audit) on success or already-terminal
       4. Errors:
          - 401/403 → raise ExecutorAuthError → daemon exit 78
          - 5xx / network → transient_retry 3x exp backoff; exhaust → log warn + return
          - 4xx already-terminal (status=ERROR or 404 with "not found / not active")
            → log info + publish CancelAcknowledged(rest_status="already_terminal")
          - other 4xx → log warn + return (do not raise)

       ReservationReleased is NOT published here — ws_dispatcher does it from WS foc.
       Safety net: fill_tracker REST poll publishes ReservationReleased(reason=
       "missing_from_venue") if WS foc never arrives.
    """
    # publish CancelRequested (4.4a 既有，不變)
    await self._bus.publish(CancelRequested(
        venue_offer_id=venue_offer_id,
        requested_at_ms=int(time.time() * 1000),
        signal_correlation_id=signal_correlation_id,
        account_id=account_id,
    ))

    # REST call wrapped in transient_retry
    submit_inner = transient_retry(self._cancel_http_call)
    try:
        response = await submit_inner(venue_offer_id, ctx)
    except ExecutorAuthError:
        raise  # propagate to daemon → exit 78
    except Transient as e:
        log.warning("bitfinex_cancel_transient_exhausted voi=%s err=%r", venue_offer_id, e)
        return

    # publish CancelAcknowledged based on response
    rest_status = self._classify_response(response)  # "success" | "already_terminal" | "other"
    if rest_status in ("success", "already_terminal"):
        await self._bus.publish(CancelAcknowledged(
            venue_offer_id=venue_offer_id,
            acknowledged_at_ms=int(time.time() * 1000),
            signal_correlation_id=signal_correlation_id,
            account_id=account_id,
            rest_status=rest_status,
            venue_response_text=self._extract_text(response),
        ))
    else:
        log.warning("bitfinex_cancel_other_error voi=%s response=%r", venue_offer_id, response)
```

```python
@staticmethod
def _parse_event(row: dict[str, Any]) -> Any | None:
    et = row.get("event_type")
    payload = row.get("payload", {})

    if et == EventType.RESERVATION_CLAIMED.value:
        return ReservationClaimed(
            cid=payload["cid"],
            venue_offer_id=payload["venue_offer_id"],
            size_usdt=Decimal(str(payload["size_usdt"])),
            signal_correlation_id=UUID(payload["signal_correlation_id"]),
            account_id=payload["account_id"],
            is_simulated=payload.get("is_simulated", False),
            venue_seq=payload.get("venue_seq"),
            event_seq=payload.get("event_seq"),
            occurred_at_ms=payload.get("occurred_at_ms"),
            recorded_at_ms=payload.get("recorded_at_ms"),
        )

    if et == EventType.ORDER_FILL.value:
        # Legacy OrderFillPayload schema bridge (mirrors ledger.py:164-173)
        return OrderFilled(
            cid=payload["cid"],
            venue_offer_id=payload["offer_id"],         # legacy field name
            credit_id=None,                              # not in legacy schema
            size_usdt=Decimal(str(payload["fill_size_usdt"])),
            fill_rate=payload["fill_price"],
            signal_correlation_id=UUID(payload["signal_correlation_id"]),
            account_id=row.get("account_id") or payload.get("account_id", ""),
            is_simulated=payload.get("is_simulated", False),
            venue_seq=payload.get("venue_seq"),
            event_seq=payload.get("event_seq"),
            occurred_at_ms=payload.get("occurred_at_ms"),
            recorded_at_ms=payload.get("recorded_at_ms"),
        )

    if et == EventType.RESERVATION_RELEASED.value:
        # ReservationReleasedPayload uses v2-aligned names already
        return ReservationReleased(
            cid=payload["cid"],
            venue_offer_id=payload["venue_offer_id"],
            size_usdt=Decimal(str(payload["size_usdt"])),
            reason=payload["reason"],
            signal_correlation_id=UUID(payload["signal_correlation_id"]),
            account_id=row.get("account_id") or payload.get("account_id", ""),
            is_simulated=payload.get("is_simulated", False),
            venue_seq=payload.get("venue_seq"),
            event_seq=payload.get("event_seq"),
            occurred_at_ms=payload.get("occurred_at_ms"),
            recorded_at_ms=payload.get("recorded_at_ms"),
        )

    return None
```

## Rationale

### D1 — AxiomReplayQueryAdapter unified-class-two-method

Hexagonal port-per-consumer (Cockburn 2005) + DRY backend connection 組合。

- **不選**「2 獨立 class 各 inherit base」：Python duck typing > nominal subtyping，1 class 滿足 2 protocol 是慣例
- **不選**「Stripe god EventStore class 含 smoke method」：smoke (3-column projection) 跟 replay (full payload) 是 genuinely 不同 read model，混在一起 violates SRP
- **代價**：兩個 method 對 protocols 是 duck-typed 巧合對齊，read code 時要 cross-reference 兩個 protocol 定義才看到契約。Trade-off 上接受

### D2 — Cancel REST + 3-event model (Request + Ack + StateChange)

Stripe / FINRA-style financial audit 慣例：low-volume 高重要性 cancel operation → 完整 explicit auditable events 勝過 event-count parsimony。

- **不選** 2-event (Request + StateChange)：lose "REST 打到了沒" debug breadcrumb，sad path (5xx network) 無法 distinguish
- **不選** 1-event (StateChange only)：lose user-intent 完全
- **代價**：happy path 多 1 個 event ~100ms 後 CancelAcknowledged 緊接 CancelRequested，可能 noise；sad path 是唯一 discriminator 所以保留

### D2.5 — WS-only state mutation invariant

4.4a 已 chose Hybrid primary + fallback (ws_dispatcher = primary, fill_tracker = REST poll safety net)。`_translate_foc` 在 4.4a 已 ship 包含 user_cancel / venue_cancel / expired 三 reason classification + 5s `recent_cancels` window（via dispatcher.handle_cancel_requested bus subscriber）。本 spec D2 只負責 publish `CancelRequested` + `CancelAcknowledged`，**不**自己 publish `ReservationReleased`，保留 single SoT。

- **不選** "executor.cancel 同步 publish ReservationReleased"：violates Single SoT；ledger.dedup key `(voi, venue_seq)` 不 match (REST 沒 venue_seq) → over-release bug，要破 G3 invariant 才能 work
- **不選** "fill_tracker 出 ReservationReleased"：cancel latency = poll interval (10-30s)，user-triggered action 太慢

### D3 — Mirror ledger.py schema bridge

Mechanical mirror，無 design 議題。account_id 從 row root 拿（axiom_sink 寫在 row level 不在 payload）；fallback payload 兼容舊 data 結構。

### D4 — Shared env var

12-factor app 慣例「separate concerns 分 config」在這沒 ROI — ledger / registry 本質同一 event log 的 replay window。Single SoT for operational coherence。

- **代價**：deploy 時 Koyeb secret rename，transition 一個 deploy cycle 雙讀兼容
